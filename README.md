## Descripción del Proyecto
Este repositorio contiene los scripts en Python desarrollados para la Tarea 3 del curso de Big Data. El proyecto demuestra el procesamiento de datos utilizando dos enfoques en una máquina virtual Ubuntu:

1. **Procesamiento Batch:** Análisis de un dataset de conexiones a internet utilizando PySpark (`analisis_batch.py`).
2. **Procesamiento en Streaming (Tiempo Real):** Envío de métricas a través de un Productor de Apache Kafka (`kafka_producer.py`) y procesamiento de micro-lotes usando un Consumidor de Spark Streaming (`spark_streaming_consumer.py`).
